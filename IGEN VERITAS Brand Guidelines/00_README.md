## The Five Non-Negotiables

Everything else is guidance. These five are rules.

1. **The gradient is the brand.** Violet `#7B67D1` → Blue Bright `#4196E6`. If a piece has no brand colour in it, it isn't ours.
2. **One idea per asset.** Max 4–6 words in a headline. If it needs a paragraph to land, it belongs in the caption.
3. **One accent word.** Exactly one word per headline gets a colour accent — never two, never zero.
4. **Truth over hype.** VERITAS is in the name. No invented stats, no fake screenshots, no results we can't show.
5. **Never distort the logo.** No stretching, rotating, recolouring, gradients-on-logo, or drop shadows.
