# Web Design — Portfolio & Demo Reference

Finished web design work used to show prospects what IGEN VERITAS builds. These are **client-facing sales assets**, not brand guideline rules.

---

## Important: These Are Not IGEN VERITAS-Branded

Every site in this folder uses **the demo brand's own identity** — its own colours, fonts and logo. That is deliberate and correct. When we build a website for a client, the client's brand leads; IGEN VERITAS appears only in the footer credit and, where applicable, the chat widget.

**So:** do not check these against `03_Color_Palette.md` or `04_Typography.md`. Those files govern *our* marketing. These files demonstrate *our craft*.

What we do check them against:

- Layout discipline — clear hierarchy, generous whitespace, one idea per section
- A single primary CTA above the fold
- Real social proof (rating, review count, years in business)
- Mobile-first responsiveness
- Fast load, clean type, accessible contrast

## How to Use These in Sales

1. **Discovery call** — show the isometric mockup first. It reads as "complete site" in one glance.
2. **Direction-setting** — show 2–3 variants that fit the client's positioning, not all seven. Seven is paralysing.
3. **Pitch deck** — one variant per slide, home page cropped to the hero, per `08_Applications.md` §8.7.
4. **Social proof post** — Template C (Proof/Demo) with the laptop frame as the centre visual.
5. **Never** present these as live client sites or invent a client name for them. They are demo builds. Say so. (`01_Brand_Overview.md` — VERITAS.)
