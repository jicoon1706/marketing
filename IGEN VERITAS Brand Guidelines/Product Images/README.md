## Web Design

`Web Design/Saloon_Website/` — 7 complete salon website design variants (35 page screenshots + 8 motion assets, ~162 MB). Portfolio and demo material for the web development service line.

**These are not IGEN VERITAS-branded** and shouldn't be checked against our palette — each uses its own demo brand identity, which is how client work is supposed to look. Full breakdown of the seven variants, which prospect each suits, and how to use them in a pitch: `Web Design/README.md`.

## What belongs in this folder

- Approved final social graphics that represent the standard well
- Product UI screenshots (chatbot widget, dashboards) with PII redacted
- Mockups used repeatedly across campaigns
- Finished website design work, under `Web Design/`

## What doesn't

- Drafts and rejected versions — those stay in `social-media/`
- Client-specific assets — those live in `clients/<name>/assets/`
- Raw source PSD/Figma exports

Source archive of all generated visuals: `marketing_team/social-media/`
Finalised poster exports: `marketing_team/poster/`
