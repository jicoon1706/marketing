## Feature-by-Feature Breakdown

### What Pabbly Actually Is

Pabbly Connect lets you link two apps together with a trigger and an action. Example: "When a form is submitted, send a WhatsApp message." It's the plumbing — useful plumbing, but plumbing.

To build what IGEN VERITAS delivers, you'd need Pabbly Connect *plus* a chatbot platform *plus* a WhatsApp API provider *plus* a lead scoring logic layer *plus* a reporting setup. Each piece requires configuration, testing, and maintenance. When the WhatsApp API changes (and it does), you're fixing it.

IGEN VERITAS uses n8n (our automation layer) the same way Pabbly is used — but we've already built the flows for your industry, tested them, and plugged them into Botpress and WABlas. The result is a system, not a stack of apps waiting to be assembled.

### Chatbot Capability

Pabbly Connect has no native chatbot. You would need to integrate a separate chatbot builder (Tidio, Landbot, Botpress, etc.), wire it into Pabbly, and configure the handoff between them.

IGEN VERITAS's chatbot is the centrepiece: it handles your FAQ, presents your full service menu, collects lead data (name, phone, email, service interest), qualifies the lead, and triggers the follow-up sequence — all in one conversation flow, in BM, English, or Mandarin.

**Bottom line:** Pabbly is part of a chatbot setup. IGEN VERITAS is a complete chatbot setup.

### WhatsApp Automation

Pabbly supports WhatsApp via API (using providers like WABlas or 360dialog). You can send messages through Pabbly workflows, but you design the message content, timing logic, and conditional branching yourself.

IGEN VERITAS Growth and Pro tiers include pre-built WhatsApp follow-up sequences — Day 1, Day 3, and Day 7 — with message copy tailored to your service. Hot leads trigger an immediate alert to the owner. This is already written and deployed as part of setup.

**Bottom line:** Pabbly can send a WhatsApp message. IGEN VERITAS sends the right message, to the right lead, at the right time — automatically.

### Lead Scoring

Pabbly has no native lead scoring. You'd need to build conditional logic in your Pabbly workflows to assign scores based on form responses — possible, but complex.

IGEN VERITAS Pro scores every lead as hot, warm, or cold based on chatbot interaction signals. Hot leads prompt a 15-minute callback alert so you can close them while intent is high. This logic is built in from day one.
