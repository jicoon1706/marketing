## Usage Rules

| Platform | Recommended Count | Placement | Notes |
|---|---|---|---|
| Instagram | 5–10 tags | End of caption or first comment | Mix core + category-specific; avoid all-generic |
| LinkedIn | 3–5 tags | End of post, inline only | Keep professional; no niche engagement bait |
| Website/Blog | 2–4 tags | Meta tags / SEO keywords | Use as keyword targets, not post tags |
| WhatsApp | 0 | N/A | No hashtags in broadcast messages |

**General guidance:**
- Always include at least 1 core brand tag (`#IGenVeritas`) on every post
- Never repeat the same hashtag set across consecutive posts — rotate to avoid shadowban risk
- Combine 2–3 categories per post for reach diversity
- Instagram: prioritize mid-size tags (50K–500K posts) over oversaturated mega-tags (5M+)

## Tags to Avoid

| Tag | Reason |
|---|---|
| `#follow4follow` `#f4f` `#like4like` | Low-quality engagement bait; damages brand credibility |
| `#love` `#instagood` `#photooftheday` | Completely irrelevant to B2B tech content |
| `#marketing` (alone) | Oversaturated (500M+ posts); near-zero discovery value |
| `#tech` (alone) | Too broad; no targeting value |
| Competitor brand names | Avoid tagging competitor brands in hashtags |
| Offensive or politically sensitive tags | Brand safety risk |

## Hashtag Rotation Strategy

To avoid algorithmic penalties and maintain reach diversity, rotate sets across posts:

- Week 1: Sets A + H (Awareness and AI)
- Week 2: Sets A + C (AI Chatbot deep-dive)
- Week 3: Sets C + D (Package reveal + web)
- Week 4: Sets E + G (LinkedIn push + engagement)

Never use the identical set on back-to-back Instagram posts.
