The AI chatbot is a **website widget** (Botpress Webchat, embedded via `<script>` tag). Customers interact with it on the client's website. WhatsApp is backend-only.

**Why:** Early content briefs and the content calendar incorrectly framed pain points around unanswered WhatsApp messages and included a "WhatsApp Keyword Triggers" section — none of which apply to the actual product.

**How to apply:**
- Pain point hooks should reference website visitors leaving without booking/engaging, not WhatsApp message responses
- `#WhatsAppBot` hashtag is wrong — use `#WebsiteChatbot`
- WhatsApp IS used in Growth/Pro, but only as a backend notification tool (owner gets alerted via WABlas when a lead books; customers get Day 1/3/7 follow-up messages) — this is not the customer-facing interaction layer
- Never include WhatsApp keyword trigger tables in content calendars — that pattern belongs to WhatsApp-native bots only
